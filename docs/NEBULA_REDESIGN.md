# 深空知识地图改版

本轮按纯色星体方向重构前端，未改变 PDF、语义布局或向量索引。

## 已实现

- 云带：文献分布协方差决定主方向，空间范围决定尺度；三种稳定形态模板、噪声域扭曲、分叉和暗尘带表现不同主题；提高连续柔雾与体积透明度，使雾状结构更明显。
- 小星星：外围星带连续环绕、微幅漂移与柔和闪烁；另设不受主题吸引的零散背景星场，使用 GPU 独立漂移与渐变亮点。中心不再铺主题装饰粒子，倾斜视角下也淡化投影到云核心的外围星点。
- 星体：单一基础色、基础自发光与柔和光照，未选中的文献同样发光；HDR 边缘亮度参与 Bloom，贴边光和外雾快速指数衰减，取消月面噪声与几何缩放式呼吸。
- 标签：默认全部文件名，支持简洁浏览、避让、引导线和完整名称提示。空间极度拥挤时全标签模式不能保证零重叠。
- 连线：真实相似度权重控制强弱，选中邻域与引用关系高亮；非相关关系淡出；移除沿线移动的点状标记。
- 导航：全景／主题／单篇三级镜头、面包屑返回、主题按钮、用户拖动中断；折叠问答栏可扩展画布。
- 问答：同步请求期间只报告等待状态；真实引用返回后依次点亮星体并持续高亮；悬停来源预览，点击来源先定位再打开原文。没有候选结果流式接口，因此不显示伪造的搜索轨迹。
- 中英文、低／高画质、中键平移、右键加入对话保留。
- 启动入口统一为 `PDF_GalaxAI.cmd`：后台启动后端、等待就绪、启动／复用前端、验证接口代理后再打开真实文献页面；界面展示后端连接状态。重复点击不重复启动，慢速初始化可继续等待已启动的进程；无关端口占用不自动结束进程。

## 自动检查

```sh
npm run typecheck
npm run test:graphics
npm run test:launcher
npm run build
```

图形逻辑测试验证云带方向、坐标不被修改、三级镜头与画布适配、引用去重、连线权重、标签避让、光晕衰减及独立背景星点漂移。它们不等同于实际浏览器 WebGL 着色器编译、视觉验收或 FPS 测试。

## 浏览器验收清单

1. 进入正常文献库，检查四个主题云带、未选中时也发光的纯色球体和近亮远淡的光晕；确认外围星带环绕、零散背景星星独立运动。不要用演示数据代替真实文献检查。
2. 依次点击主题、星体、主题面包屑、全景，确认镜头返回；拖动可中断镜头动画。
3. 默认文件名应显示；切换简洁浏览后，远景显示主题，主题近景展开文件名，悬停和选中时显示名称。
4. 中键拖动平移；右键点击星体或文件名加入对话，左键拖动只旋转。
5. 提问期间无虚构的命中节点；回答返回后真实引用节点持续高亮。无引用的通用对话不点亮文献。
6. 点击引用：完成镜头定位后打开对应 PDF，保留页码与片段高亮。快速点击另一个引用或导航应取消旧的待打开引用。
7. 折叠／展开问答面板，切换语言与画质，并在较窄窗口检查工具栏和详情卡片。

## 作品集表述边界

可介绍数据驱动的程序化形态、屏幕空间标签管理、分层探索和证据可视化。
光照与光雾是艺术化近似；不存在完整天体物理模拟。方法的可读性和性能优势仍需对照实验，不应仅凭改版截图声称科研创新或效率提升。
